/---------------------------------------------\
| INSTALLATION DE MONTJOIE EN MODE SEQUENTIEL |
\---------------------------------------------/

Librairies nécessaires :
sudo apt-get install make cmake
sudo apt-get install gfortran g++
sudo apt-get install git

Dans toute la suite, pensez à remplacer gcastera par votre session personnelle

-----------------------------------------------------------------------

Créer une clef ssh pour GitLab :
Dans le répertoire de base /home/gcastera/
ssh-keygen -t rsa
Le terminal affiche "Enter file in which to save the key (/home/gcastera/.ssh/id_rsa):", appuyer juste sur enter sans rien renseigner
Ensuite "Enter passphrase (empty for no passphrase):"
et "Enter same passphrase again:"
mettre éventuellement un mot de passe (optionnel)
cat .ssh/id_rsa.pub
Copier tout ce qui s'affiche
aller sur GitLab >> en haut à droite Edit Profile >> dans la barre de gauche SSH Keys
et créer une nouvelle clef en collant ce qui vient d'être copié

-----------------------------------------------------------------------

Se placer dans le répertoire où on souhaite cloner le dossier montjoie, par exemple dans ~/Documents/
git clone git@gitlab.inria.fr:pianotouch/montjoie.git
cd montjoie
mkdir SOLVE-SEQ
cd SOLVE-SEQ

-----------------------------------------------------------------------

Blas

wget http://www.netlib.org/blas/blas.tgz
tar zxvf blas.tgz
cd BLAS-3.10.0
make
mv blas_LINUX.a libblas.a
cd ..

-----------------------------------------------------------------------

CBlas

wget http://www.netlib.org/blas/blast-forum/cblas.tgz
tar zxvf cblas.tgz
cd CBLAS
Modifier le chemin ou est Blas (variable BLLIB) dans Makefile.in
# BLLIB = /home/gcastera/Documents/montjoie/SOLVE-SEQ/BLAS-3.10.0/libblas.a
make
mv lib/cblas_LINUX.a libcblas.a
ar rv libcblas_mkl.a src/zdotcsub.o src/zdotusub.o src/cdotcsub.o src/cdotusub.o
cd ..

-----------------------------------------------------------------------

Lapack

mkdir lapack-sandbox
cd lapack-sandbox
mkdir lapack-build
git clone https://github.com/Reference-LAPACK/lapack-release.git
cd lapack-build
cmake ../lapack-release
make
mv lib/liblapack.a liblapack.a
cd ../..

-----------------------------------------------------------------------

Metis

wget http://glaros.dtc.umn.edu/gkhome/fetch/sw/metis/metis-5.1.0.tar.gz
tar zxvf metis-5.1.0.tar.gz 
cd metis-5.1.0
make config
make
mv build/Linux-x86_64/libmetis/libmetis.a .
cd ..

-----------------------------------------------------------------------

Scotch

wget https://gforge.inria.fr/frs/download.php/file/34618/scotch_6.0.4.tar.gz
tar zxvf scotch_6.0.4.tar.gz
sudo apt-get install zlib1g-dev
cd scotch_6.0.4/src
cp Make.inc/Makefile.inc.i686_pc_linux2 Makefile.inc
Remplacer gcc par mpicc dans Makefile.inc, et -Drestrict=__restrict par -Drestrict=
make
make ptscotch
make esmumps
make ptesmumps
cd ../..

-----------------------------------------------------------------------

Mumps

wget http://graal.ens-lyon.fr/MUMPS/MUMPS_5.2.1.tar.gz
tar zxvf MUMPS_5.2.1.tar.gz
cd MUMPS_5.2.1
cp Make.inc/Makefile.debian.SEQ Makefile.inc

A modifier dans Makefile.inc :

// LSCOTCHDIR = /home/***/Documents/montjoie/SOLVE-SEQ/scotch_6.0.4
// ISCOTCH = -I$(LSCOTCHDIR)/include
// LMETISDIR = /home/gcastera/Documents/montjoie/SOLVE-SEQ/metis-5.1.0
// IMETIS    = -I$(LMETISDIR)/include
// ORDERINGSF = -Dmetis -Dpord
Attention à ne pas laisser d'espaces résiduels après les chemins

make alllib
cd ..

-----------------------------------------------------------------------

cd ../MONTJOIE
cp Makefile.LINUX Makefile

Dans le Makefile :
USE_BLAS := YES
OPTIMIZATION := FASTER
STATIC_COMPILATION := YES
USE_MUMPS := YES
Mettre toutes les autres librairies à NO (y compris scotch)

Vérifier les chemins:
EXTERNAL := /home/gcastera/Documents/montjoie/SOLVE-SEQ
(le dossier où viennent d'être installées toutes les librairies)
CHESELDON := /home/gcastera/Documents/montjoie/SELDON
(le dossier de SELDON qui est une librairie d'algèbre linéaire)
puis les chemins de mumps, scotch et metis juste au dessous

Dans la section ifeq($(USE_BLAS), YES), changer BLAS-3.8.0 en BLAS-3.10.0

Dans la section ifeq($(USE_MUMPS), YES), -L$(HOME)/common/lib devient -L$(HOME)/Documents/montjoie/MONTJOIE

Compiler montjoie (c'est très long):
make -j4 acous2D

S'il n'y a pas d'erreur, c'est gagné !

-----------------------------------------------------------------------

Dernière étape avant de pouvoir lancer des simulations
Ajouter la ligne suivante dans le .bashrc:
export LD_LIBRARY_PATH=${LD_LIBRARY_PATH}:/home/gcastera/Documents/montjoie/MONTJOIE/lib
Puis :
source .bashrc

-----------------------------------------------------------------------

Pour que git ignore le dossier Solve qu'on ne veut surtout pas commiter:
cd Documents/montjoie/.git/info
Ajouter ces lignes dans le fichier "exclude":
/SOLVE-SEQ
*Makefile*
*.DS_Store

Cette étape permet à git d'ignorer les fichiers spécifiés
Si on créé par la suite un dossier /MONTJOIE/simulations il faudra le rajouter
dans cette liste.

-----------------------------------------------------------------------------------------------|
FIN DE L'INSTALLATION SEQUENTIELLE
-----------------------------------------------------------------------------------------------|

A modifier dans Bmake.inc :
Changer BTOPdir vers le répertoire où est BLACS et mettre :
# MPIdir = /usr/share/openmpi
# MPILIBdir = /usr/lib/x86_64-linux-gnu/openmpi
# MPIINCdir = /usr/include/x86_64-linux-gnu/openmpi
# MPILIB = $(MPILIBdir)/libmpi.so
Remplacer TRANSCOMM = -DUseMpich par TRANSCOMM = -DUseMpi3
Remplacer F77 = g77 par F77 = mpif77 et mettre CC = mpicc

make mpi
cd LIB
ar xv blacsCinit_MPI-LINUX-0.a
ar xv blacs_MPI-LINUX-0.a
ar rv libblacs.a *.o *.C
rm *.o *.C
mv libblacs.a ../

cd ../MONTJOIE
cp Makefile.LINUX Makefile

Dans le Makefile :
USE_BLAS := YES
OPTIMIZATION := FASTER
STATIC_COMPILATION := YES
USE_MUMPS := YES
USE_ARPACK := YES
USE_OPENMP := YES
USE_MPI := YES
USE_SCOTCH := YES
Mettre toutes les autres librairies à NO

Vérifier les chemins:
EXTERNAL := /home/gcastera/Documents/montjoie/SOLVE-PAR
CHESELDON := /home/gcastera/Documents/montjoie/SELDON
CHEMUMPS_PAR = $(EXTERNAL)/MUMPS_5.2.1
CHESCOTCH = $(EXTERNAL)/scotch_6.0.4
CHEMETIS = $(EXTERNAL)/metis-5.1.0


Dans la section ifeq($(USE_BLAS), YES), changer BLAS-3.8.0 en BLAS-3.10.0
et mettre le bon chemin pour $(EXTERNAL)/lapack-sandbox/lapack-build/liblapack.a

Dans la section ifeq ($(USE_SCALAPACK),YES), mettre la bonne version scalapack-2.1.0

Dans la section ifeq ($(USE_ARPACK),YES), mettre le bon chemin vers Parpack (et non PARPACK) :
# if arparck is needed
ifeq ($(USE_ARPACK),YES)
   FLAGS := $(FLAGS) -DSELDON_WITH_ARPACK
   ifeq ($(USE_MPI),YES)
      LIB := -L$(EXTERNAL)/Parpack -lparpack -larpack $(LIB)
   else
      LIB := -L$(EXTERNAL)/Parpack -larpack $(LIB)
   endif
endif

Dans la section ifeq($(USE_MUMPS), YES), -L$(HOME)/common/lib devient -L$(HOME)/Documents/montjoie/MONTJOIE

Compiler montjoie (c'est très long):
make -j4 helm2D
Si vous avez plus de coeurs (x coeurs par exemple) vous pouvez taper -jx

S'il n'y a pas d'erreur, c'est gagné !
